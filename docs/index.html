Endpoints de la API

Base URL: https://actividad3-tutillo-jefferson-production.up.railway.app/api

MetodoRutaDescripcionResponse ejemplo
GET/healthEstado de la API{ "success": true }
GET/api/productsLista todos los productos[{ "_id", "name", "price", ... }]
GET/api/products/:idObtiene un producto{ "_id", "name", "price", ... }
POST/api/productsCrea un producto{ "_id": "nuevo_id", ... }
PUT/api/products/:idActualiza completo{ "_id", "name": "actualizado" }
PATCH/api/products/:idActualiza parcial{ "_id", "stock": 5 }
DELETE/api/products/:idElimina un producto{ "message": "Producto eliminado" }
GET/api/categoriesLista categorias[{ "_id", "name" }]
POST/api/categoriesCrea una categoria{ "_id", "name" }
DELETE/api/categories/:idElimina categoria{ "message": "Categoria eliminada" }

Guia de Ejecucion Local

Requisitos

  • Node.js v18 o superior
  • npm v9 o superior
  • Cuenta en MongoDB Atlas (o MongoDB instalado localmente)

Backend

git clone https://github.com/04Steve05/Actividad3-Tutillo-Jefferson
cd Actividad3-Tutillo-Jefferson/backend
npm ci
cp .env.example .env
# Edita .env con tus valores reales (MONGODB_URI, SESSION_SECRET, etc.)
npm run seed    # Carga categorias y productos de prueba
npm run dev     # Servidor en http://localhost:3000

Frontend

cd Actividad3-Tutillo-Jefferson/frontend
npm ci
cp .env.example .env.local
# Edita .env.local: VITE_API_URL=http://localhost:3000
npm run dev     # App en http://localhost:5173

Build para produccion

cd frontend
npm run build   # Genera la carpeta dist/
npm run preview # Previsualiza el build en localhost:4173
