Endpoints de la API

Base URL: https://actividad3-tutillo-jefferson-production.up.railway.app/api

MétodoRutaDescripción
GET/healthEstado de la API
GET/api/productsLista todos los productos
GET/api/products/:idObtiene un producto
POST/api/productsCrea un producto
PUT/api/products/:idActualiza completo
PATCH/api/products/:idActualiza parcial
DELETE/api/products/:idElimina un producto
GET/api/categoriesLista categorías
POST/api/categoriesCrea una categoría
DELETE/api/categories/:idElimina categoría

Ejecución Local

Backend

git clone https://github.com/04Steve05/Actividad3-Tutillo-Jefferson
cd Actividad3-Tutillo-Jefferson/backend
npm ci
cp .env.example .env
# Completa .env con MONGODB_URI y SESSION_SECRET
npm run seed   # carga productos y categorías de prueba
npm run dev    # http://localhost:3000

Frontend

cd ../frontend
npm ci
cp .env.example .env.local
# Edita .env.local: VITE_API_URL=http://localhost:3000
npm run dev    # http://localhost:5173
